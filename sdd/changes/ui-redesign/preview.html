6 · Copy en criollo — la jerga es el apellido, no el nombre

Pasale el mouse por las palabras punteadas: tooltip con la traducción técnica.

🪪

Credencial

attestation SAS

Un verificador confirma que hay un humano detrás de la wallet del agente. Solo se ve nivel + fecha — nunca datos personales.

✍️

Permiso

mandato on-chain

El dueño firma los límites: cuánto por pago, cuánto por día y a quiénes puede pagarle. Lo puede revocar cuando quiera.

🧾

Recibo

PaymentReceipt

Cada pago deja un recibo público: quién pagó, a quién, cuánto y cuándo. Es la prueba si hay una disputa.

En código y detalles la jerga sigue intacta — es para devs:

services/service-z/src/index.ts
// el servicio verifica el recibo on-chain — ~10 líneas, sin API key
