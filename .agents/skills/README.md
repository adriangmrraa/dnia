# 10 skills locales SDD preinstaladas en ZIP
Estas skills son originales del kit y legibles por cualquier modelo con acceso al filesystem. No garantizan autodetección en todos los agentes. En ese caso leer cada `SKILL.md` por ruta. Orden y criterios en `harness/SDD_PLAYBOOK.md`. Las skills Matt Pocock y Solana son EXTERNAS y requieren instalación aparte si se eligen.
